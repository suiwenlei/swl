# uniapp-mall

Quickstart UniApp scaffold with an e-commerce style home screen.

## Run (H5)

Requires Node v20.18.3. Use nvm or asdf:

```bash
nvm use
# or
asdf install && asdf local nodejs 20.18.3
```

```bash
npm i
npm run dev:h5
```

Build for H5:

```bash
npm run build:h5
```

For App or Mini-Program, open the project in HBuilderX and run the corresponding build.
